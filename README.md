hulkmacaron 앱들의 **빌드 전용** 공개 저장소입니다. 앱 소스·서명키·빌드 결과물은 이곳에 없습니다(비공개 저장소에서 가져와 빌드 후 비공개 저장소로 되돌려 보냄).

- `.github/guard.sh` 가 키스토어·비밀번호·앱 소스가 올라오면 빌드를 실패시킵니다.
